# 叙事、过渡与段首点题

## 点题链（缺一补一）

1. 摘要后半：论题关键词 + 结构预告  
2. 背景末过渡：难点/质量属性 → 导入本题  
3. Q2 段首：点明「以下阐明…」  
4. 每一实践段首：先写论题相关问题，再写手段  
5. 结尾：再次呼应具体论题（非空泛「本项目成功」）

## 过渡句模板

**背景 → Q2：**  
「于是笔者决定在**高并发保障**（换成题面主题）方面重点突破。下文首先阐明相关技术要点，再结合本项目论述具体实践。」

**Q2 → 实践：**  
「基于对上述…特性的分析，结合本项目在…方面的核心需求，我们决定采用…。以下从三个方面展开论述。」

**实践段首（手段类）：**  
「针对…业务…的**高并发**流量特征，我们从**水平扩容**（题面手段之一）角度…」

**实践段骨架：**  
场景问题 → 选用手段（加粗）→ 在本模块如何做 → 指标/效果

## 技术写法

- 正：「使用 **Kubernetes** 按负载自动增减 Pod；使用 **RabbitMQ** 削峰填谷。」  
- 反：「核心技术栈包括：Redis、Kafka、ES、ShardingSphere…」（账单式）

## 表达禁令

- 口语化（「咱们」「搞定」「超级多」）  
- 单段过长（建议实践段 ≤450 字）  
- 全局 1.2.3. 答题腔（段首主题词优先）  
- 教学小标题（「项目背景介绍」「子题目二」）  
- 摘要物理分段（逻辑两层写在一段内）

## 加粗建议

- Q2：每个列举项名  
- 实践/结尾：QPS、P99、可用性、核心决策词  
- 勿整句加粗；每段 1–3 处即可
